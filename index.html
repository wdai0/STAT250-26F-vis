How to use this site

Select a visualization from the tabs. Use its controls to examine a statistical question, and use Reset to return to the starting settings.

Download saves a complete HTML file that you can open in a browser offline or edit for your own use. It saves the visualization, not your current settings or simulation results.

Working with a visualization

  1. Start with a question. Identify the variables, units, groups, and quantity of interest. Check whether the display uses observed data or a simulation.
  2. Compare deliberately. Change one setting at a time and compare the result. Check that groups use consistent numerical scales and histogram bins. Changing bin width should change only the histogram; filtering observations can change counts and summaries.
  3. Check the evidence. Read graphs together with numerical summaries, group sizes, and missing-value counts. Check units and any stated quartile or boxplot-whisker conventions. Small groups and random variation can make patterns unstable.
  4. Explain the result in context. Connect what you see to the statistical ideas covered in class. State the limitations of the data, study design, or model; an association alone does not establish causation.

Optional AI-assisted data exploration

You may use Patriot AI with the course prompt template to explore a dataset and a research question of your own.

  • Adapt the prompt. Specify your dataset, variables, and research question rather than leaving the example details unchanged.
  • Revise and ask follow-up questions. The first result may need correction. Ask why a graph or method was chosen, request alternatives, or ask for a clearer interpretation.
  • Verify the result. Compare the output with the supplied data and course concepts. AI can misread variables, make calculation errors, or suggest inappropriate analyses.
  • Use it to support your reasoning. AI-generated explanations and visualizations are additional learning resources, not substitutes for your statistical understanding.
  • Protect sensitive data. Do not upload confidential or personally identifiable information without explicit authorization. Use de-identified or simplified data when appropriate.

This AI-assisted activity is optional and is not required for the course. Material that depends specifically on using these AI tools will not appear on exams or quizzes.

Prompt template for descriptive data exploration

Replace the bracketed fields and adapt the requested displays to your question.

Create a self-contained interactive HTML visualization using only the attached [dataset] to investigate [research question].

Let me choose among [numerical variables], inspect a histogram with adjustable bin width, and compare distributions across [grouping variable] using side-by-side boxplots.
Include group filters, a reset button, and an option to show individual observations.
Report valid observation counts, missing-value counts, mean, median, standard deviation, and IQR for the selected data and each displayed group.

Keep comparison scales and histogram bin boundaries consistent across groups, including when a group is hidden.
Changing bin width must not change the data or numerical summaries.
Confirm units from the supplied documentation, label unverified units, and explain the quartile and whisker conventions.
Preserve recorded categories and distinguish totals from rates or per-unit measurements where relevant.

Keep the layout simple, with readable labels and no unnecessary animation.
Keep this exploration descriptive: do not add causal claims, rankings, or significance tests.
Return one complete HTML file that works offline, with brief instructions for opening it.
