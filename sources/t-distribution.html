For the same estimated SE, the larger t multiplier gives a wider interval than the normal multiplier.

For a mean, the true standard error is σ/√n. Usually σ is unknown, so we estimate it using s. The t reference distribution accounts for the uncertainty introduced by estimating that spread.

T =X̄ − μ₀S / √n,   df = n − 1

Which quantity follows t?

The standardized statistic T follows t, not the raw observations or the unstandardized sample mean.

This is an exact result for independent observations from a normal population under H₀: μ = μ₀. For nonnormal populations, the approximation requires suitable conditions; n ≥ 30 is not a universal guarantee.

What changes with df?

Smaller df give heavier tails. As df increases, t approaches the standard normal. No finite df makes them exactly identical.

Varying df here isolates the standardized reference curve. It does not simulate repeated samples or show a raw-scale sampling distribution narrowing. In a real study, changing n also changes SE.

Symmetry, spread, and interpreting tail probabilities

Both curves are symmetric about zero and each has total area one. The ordinary t distribution is shown with location zero and scale one; this does not mean its SD is one. Its variance is df/(df − 2) for df > 2 and is not finite for df ≤ 2. At df = 1 its mean is undefined, so zero is best described as the symmetry center.

The relation df = n − 1 is for the one-sample t procedure; degrees of freedom can be defined differently in other uses of t.

A displayed tail probability is a p-value only when the cutoff is the observed test statistic and the curve is its null reference distribution, with the tail choice matching the alternative. It is not the probability that the null hypothesis is true.
