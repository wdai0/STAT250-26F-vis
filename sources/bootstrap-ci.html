Method

Each n has its own original binary sample with exactly 75% successes. For each sample, 10,000 resamples of size n are drawn with replacement; the 2.5th and 97.5th percentiles give the interval. Changing n selects a different original sample, not a larger resample from one fixed sample. Seeds are fixed for reproducibility.
