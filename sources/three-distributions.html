Methods

Sampling sources

Sampling: independent Bernoulli draws with assumed p = 0.28. Bootstrap: resample the fixed 32 ones and 68 zeros with replacement. Null: independent Bernoulli draws with p₀ = 0.20, rather than label permutations.

Repetitions and sample size

Each repetition has n = 100 outcomes and contributes one proportion. B counts repetitions; increasing B improves simulation precision while n stays fixed.

Reproducibility

The three sources use separate seeded random streams. The p slider regenerates sampling only; the same seed and settings reproduce results.

Right-tail p-value

Count null proportions ≥ 0.32, including ties, and divide by B. This is not the probability the null is true. Zero simulated extremes does not mean zero tail probability.
